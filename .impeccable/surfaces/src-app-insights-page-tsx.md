# Oversight surfaces: Insights, Guided demo, Settings (surface brief)

Scope: `/insights`, `/demo` (`?tab=guide&step=1..8|map|notes|real`) and `/settings` (`?tab=routing|demo|integration|contacts|preferences`), mode **Operate**. These are not bench screens: they are the director/presenter and admin surfaces. Audience: the Director of Operations and the medical director watching the guided synthetic demonstration (read only), the presenter (the author, acting as Tanya Brooks, supervisor) driving it, and the supervisor maintaining routing rules, contacts and the simulated connectors. Task: Insights shows how a pilot would measure the bench, with every definition visible and nothing presented as measured; the guide walks one multipart case in eight steps whose progress is read from the records, with "Run simulator events for this step", speaker notes, the real-vs-simulated table and the workflow map; Settings holds routing rule versions, demo controls, what is simulated per connector, office contacts and per-browser preferences. Constraints: PRODUCT.md (synthetic data, fictional names, simulated connectors labeled, Unknown stays Unknown, no savings, rates, scores, rankings, AI confidence or fake activity, never live EMA sync), docs/redesign/visual-system.md (severity ladder: red only for patient identity, failures and offline amber, done quiet; PAS yellow only for PAS; type scale; hairline sections, no card in card; 44px targets at 1024; 200% zoom reflow), server commands, payloads, roles and guided-demo step logic unchanged.

## Direction contract
THESIS: The oversight surfaces read like the lab's own working papers in the same H&E ink: a report whose every number wears its "illustrative" label and lines up the prior days against today for comparison, a presenter's script with one clear next action per step, and a settings binder where what is simulated is said once, plainly. It refuses the KPI-tile dashboard, the stack of identical shadowed cards, and the "A · B · C" meta line.
OWN-WORLD: The shared H&E world, lent unchanged: hematoxylin ink and primary actions, eosin only for focus, cool bench-gray ground, white evidence sheets with hairline sections, Atkinson Hyperlegible Next for words and Mono only for identifiers (IdText in running text), the severity ladder (amber with a triangle for failures, offline sources and unknown outcomes; quiet muted check for done; neutral ink for waiting; red never used on these screens), dashed honesty chips for "Illustrative", "Simulated", "Synthetic". Charts use the token ramp (indigo age steps, brand bars) read from the CSS variables, so they match the Operations owner bars.
STORY: The director reads Insights top to bottom: one honest statement that nothing here is measured, the measures as sheets, each with its prior-day-versus-today comparison table (median, 90th percentile, n, still open, missing) instead of tiles, a definition under every chart, then the blank scenario worksheet. The presenter opens a guide step, reads the title at lg, presses the one primary action, sees the run's result swap in, and moves to the next step by name.
FIRST VIEWPORT: Insights: title with its "Synthetic data only" chip, the honesty note, the jump list of measures, the filter bar, the first chart sheet. Guide: title, progress and clock line, tabs, the step rail (one hairline sheet, the current step selected with fill and a 1px brand outline), and the step sheet with its title, scripted time, cast and "Run simulator events for this step". Settings: title with "Simulated: connectors", tabs with counts in words, the tab's sheets.
FORM: Extends the Intake world. User-pinned: the user's instruction for this redesign reads "Focus first on making the accessioning workstation excellent. Keep the active case and specimen identity visible, align evidence for comparison, and make the next action clear. Then extend the selected design language to the other screens." The selected language is the Intake H&E workstation (concept A, chosen on the brief's ordering). No concept-seed roll ran for these screens, by design: the user asked for extension of one selected language, not a new direction; this is a consistency pass, not a reinvention. Screen-specific form: aligned comparison tables replace timing tiles (the user's "align evidence for comparison"); the guide's step rail mirrors the Intake step rail (quiet done, ink current).
FINISH: Captured at 1440, 1366 and 1024 plus 200% zoom (720x450 and 683x384 at 2x) for Insights, guide step 1, guide step 8 after a simulator run, speaker notes and every Settings tab; looked at, fixed, recaptured once; no horizontal page scroll; tsc and the demo domain tests green; e2e assertions for these screens updated at equal strength.
