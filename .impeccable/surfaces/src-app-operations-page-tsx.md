# Operations view (surface brief)

Scope: `/operations`, mode **Operate**. Audience: the histology supervisor (Tanya Brooks) checking the bench several times a day; the Director of Operations and medical director watch it read-only in the guided demo. Task: in one look, where today's specimens are in the bench path, what is blocked right now, who owns the next step, how long it has waited, and the record behind every number. Constraints: PRODUCT.md (honest labels, synthetic data, simulated sources, no rates, scores, health percentages, savings or rankings; Unknown stays Unknown), docs/redesign/visual-system.md (severity ladder, type, layout, motion), read-only for director roles, every count links to its records, server safeguards untouched (read-only view; query gains derived fields only). Baseline problem: nine equal KPI tiles where zeros and 62 routine attestations weigh the same as three holds.

## Direction contract
THESIS: The supervisor reads the bench as a path and the exceptions as a short, owned list. One focal area answers "what is blocked now, by whom, since when, shown where"; the path and the owner queue stay quiet around it. It refuses the KPI-tile dashboard and the equal-weight table of everything.
OWN-WORLD: The shared H&E world, lent unchanged: hematoxylin ink and shell, cool bench-gray ground, white evidence sheets with hairline sections, eosin only for focus. Atkinson Hyperlegible Next for words, Mono only for identifiers (H-, CLR-, PJ-, INT-, D26-). Severity ladder: patient identity red with octagon, data-may-be-wrong amber with triangle, hold hatched ink with pause icon, waiting neutral with the owner's name, done muted. Specimen-label signature: each blocked item leads with its identifier set like a label reference (white ground, 1.5px ink outline, mono id; dashed for provisional INT- ids), scope written beside it, set with the shared LabelRef. Patient identity is a filled octagon (reads as an octagon at 18px).
STORY: The supervisor scans the bench path left to right (intake to delivered; counts, oldest wait with the record that shows it, hatched holds where they sit), reads one sentence that names how many holds and other items wait on a person and which has waited longest, then works down the "Blocked now" sheet: scope, why, next step, owner, waiting since, evidence. Patient-identity items lead the list (top rung). Routine source-system entry and the owner queue sit below and beside it, quieter: one-line muted rows grouped by owner (records nobody owns first), each group's shared status, owner and next step said once in its heading; each row carries only the record, its wait and its own evidence link. Zeros collapse into one "Clear now" line on the unfiltered list; under a filter, one sentence says what is (not) shown.
FIRST VIEWPORT: Page title with the honesty note (computed from synthetic records at the demo clock), the bench path as one hairline-divided sheet across the full width, then the "Blocked now" sheet as the dominant white surface (finding sentence at lg, category filter, the exception table). At 1366+ a right column carries "Waiting by owner" (stacked age bars, ordinal ramp, direct labels, table view) and source freshness. At 1024 everything stacks; 44px targets.
FORM: Extends the Intake world. User-pinned: the user's instruction for this redesign reads "Focus first on making the accessioning workstation excellent. Keep the active case and specimen identity visible, align evidence for comparison, and make the next action clear. Then extend the selected design language to the other screens." The selected language is the Intake H&E workstation (concept A, chosen on the brief's ordering). No concept-seed roll ran for this screen, by design: the user asked for extension of one selected language, not a new direction. Screen-specific form: the bench path as a stage/queue composition with one focused "Blocked now" area; no equal KPI tiles (the lead's composition for this job, from the baseline review in docs/redesign/references-and-skills.md).
FINISH: Captured at 1440/1366/1024 for supervisor, read-only director, source offline and filtered/empty states, plus 200% zoom (720x450, 683x384: the bench path wraps to two lines of five, the blocked table folds to two columns below 768px, table headers stop sticking below 560px tall); looked at, fixed, recaptured; tsc and domain tests green; e2e assertions for test 8 updated to the new structure and kept at least as strong.
