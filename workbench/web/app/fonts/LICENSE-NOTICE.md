Unmodified copies of the files already vendored by the Histology Lab OS app (`src/app/font-files/`), loaded with `next/font/local` so the build never needs the network. Chosen for legibility (the family was designed by the Braille Institute for low-vision readers); the mono face is used only for hashes, identifiers and coordinates.

Before any redistribution beyond this private repository, add the full OFL 1.1 text as `OFL.txt` next to these files.
